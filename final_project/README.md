Exoplanet Transit Depth: Theory and Distribution

This project analyzes exoplanet transit depth using data from the NASA 
Exoplanet Archive.

Usage:
Run "astron98_final_project.ipynb" with "data2025.csv" in the same folder.

Libraries:
NumPy, Pandas, Matplotlib, SciPy

Summary:
This project tests whether transit depth follows the trend of 100(R_p/R_*)^2
and studies how exoplanets are distributed across transit depth ranges.
